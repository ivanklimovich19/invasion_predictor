# Выявление потенциальных мест произрастания инвазивных видов растений Беларуси (Random Forest)

Скрипты на R для построения прогнозных карт климатической пригодности территории Беларуси для трёх инвазивных видов растений:

- амброзия полыннолистная (*Ambrosia artemisiifolia* L.);
- эхиноцистис лопастный (*Echinocystis lobata* (Michx.) Torr. et Gray);
- клён ясенелистный (*Acer negundo* L.).

Разработано в ГНУ «Институт экспериментальной ботаники имени В.Ф. Купревича НАН Беларуси»

## Что делает код

1. Читает таблицу геопривязанных находок вида (CSV).
2. Загружает 19 биоклиматических слоёв WorldClim 2.1 и обрезает их по прямоугольнику 23–33° в. д., 51–57° с. ш.
3. Генерирует фоновые точки (псевдоотсутствия).
4. Обучает модель Random Forest (500 деревьев, равное число присутствий и фона в каждом дереве).
5. Оценивает модель (ROC-кривая, AUC) и важность предикторов (Mean Decrease Accuracy), строит кривые отклика для трёх главных предикторов.
6. Строит карту вероятности присутствия вида (от 0 до 1).
7. Анализирует ареал: выпуклые оболочки (MCP), ядерная оценка плотности находок (KDE 50 % и 95 %), динамику ареала по периодам.
8. Сводит статистику находок: обилие, местообитания, антропогенность.

Градации карты: более 0,6 – высокая пригодность; 0,3–0,6 – средняя; менее 0,3 – низкая.

## Быстрый старт

Требуются R и RStudio, доступ к сети Интернет при первом запуске (загрузка WorldClim и границ).

```bash
git clone <ссылка на репозиторий>.git
cd <каталог репозитория>
```

```r
install.packages(c("geodata", "terra", "raster", "dismo",
  "randomForest", "pROC", "pdp", "ggplot2", "dplyr", "tidyr",
  "lubridate", "readr", "purrr", "sf", "sp",
  "rnaturalearth", "rnaturalearthdata", "adehabitatHR"))

setwd("путь/к/каталогу")
source("ojkoppo.R")      # амброзия
```

Таблицу находок вида положите в рабочий каталог и укажите её имя в строке чтения данных скрипта.

## Формат входных данных

CSV с разделителем `;`:

| Поле | Содержание |
|---|---|
| `longitude`, `latitude` | координаты, десятичные градусы, WGS 84 |
| `date` | дата находки, ДД.ММ.ГГГГ |
| `abundance` | обилие, баллы 1–4 |
| `habitat` | тип местообитания |
| `anthropogenization` | уровень антропогенности (A, B, C) |

Исходные данные о находках в репозиторий не включены.

## Выходные файлы

Растр вероятности присутствия, карты прогноза (PNG), график важности предикторов, кривые отклика, карты ареала (`area_map.png`, `dynamics_mcp.png`, `kde_2020.png`), сводные таблицы в консоли R.

## Воспроизводимость

Случайные выборки фиксируются командой `set.seed(123)`. При каждом применении фиксируйте версию кода (метку или коммит), версии R и пакетов, дату запуска и версию таблицы находок.

## Ограничения

- Модель учитывает только климат; почвы, землепользование и источники заноса не учитываются.
- Карта показывает климатическую пригодность, а не фактическое наличие вида: наличие подтверждается только полевым обследованием.
- AUC, рассчитанный на обучающей выборке, завышен; для оценки качества используйте OOB-ошибку или (пространственную) кросс-валидацию.
- Разрешение растров определяет размер выделяемых участков; узкие поймы и мелкие насаждения не выделяются.
